# voyage

<p align="center">
  <img src="./assets/readme/hero.jpg" width="100%" alt="Voyage: travel planning and itinerary construction — books flights, hotels, and keeps trip logistics synchronized">
</p>

Voyage manages the full travel planning workflow: destination research, flight and hotel comparison, itinerary construction, and reservation management. It integrates with Spot for restaurant bookings and Sands for calendar events so trip context stays synchronized.

**Capabilities:**
- Destination research and logistics planning
- Flight and hotel comparison
- Synchronized trip context across Spot and Sands
