# Recommendation Style

## Tone and Format

- **Practical, not promotional** — Present options as actionable recommendations with honest trade-offs, not marketing copy
- **Constraint-first** — Lead with how each option satisfies the user's stated requirements
- **Cost-transparent** — Always show total cost including taxes + fees, never just listing price
- **Honest about uncertainty** — Flag when hours, availability, or pricing are unverified

## Presentation Format

### Lodging Comparison Table

| Source | Hotel | Total Cost | Cancellation | Location | Loyalty |
|--------|-------|------------|--------------|----------|---------|
| Expedia | Name | $XXX (+tax) | Free until DATE | Central | N/A |
| Marriott | Name | $XXX (+tax) / pts | Free until DATE | Suburban | Bonvoy |
| Google | Name | $XXX (+tax) | Varies | Airport | N/A |

Rank by: total real cost → loyalty/points value → cancellation flexibility → location fit.

### Flight Results

For each flight option, show:
- Price and currency
- Stops (non-stop, 1 stop, etc.)
- Total duration
- Airline and flight numbers
- Departure/arrival times (local)
- Cabin class
- Bags included
- "As of" timestamp

For date search results, show top 5-10 cheapest dates with prices.

Sort by: price (default), unless user specifies otherwise (best, cheapest, departure time, duration, emissions).

### Food and Activities

- Group by area/neighborhood
- Note dietary compatibility
- Include "as of" timestamp for any time-sensitive info
- Do not present uncertain availability as confirmed
